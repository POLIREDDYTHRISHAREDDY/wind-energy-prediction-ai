# Wind Energy Prediction Using AI

## Project Overview
This project focuses on predicting wind energy using historical wind-related data and machine learning techniques. It aims to analyze patterns in the data and evaluate models for wind energy prediction.

## Objectives
- Analyze historical wind energy data.
- Preprocess data and identify useful patterns.
- Train and compare machine learning models.
- Evaluate model performance to identify a suitable prediction model.

## Dataset
The project uses historical wind energy data from 2015–2024 associated with Chikkamagaluru. Dataset details and source should be added here.

## Technologies Used
- Python
- Pandas and NumPy
- Matplotlib and Seaborn
- Scikit-learn
- Jupyter Notebook

## Machine Learning Models
- Linear Regression
- Random Forest Regressor
- Gradient Boosting Regressor
- Support Vector Regression (SVR)

## Project Workflow
1. Data collection
2. Data preprocessing
3. Exploratory data analysis and visualization
4. Model training
5. Model evaluation and comparison
